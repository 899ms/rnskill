# 母版、状态表与出图提示词

## 让力量可读

尺度感来自清楚的小人、可辨建筑与越过屋顶的巨相。沿母版安排本体在下部、巨相在后上方，比例不机械写死；脸、手、武器轨迹留可读空间。两个人悬浮或单独大脸特写不能表达同源法相。

力量用因果呈现：积水涟漪→水圈抬起→石屑升起→法相显现→水向刃口聚拢→斩击推动水幕→水石回落。避免全程均匀粒子漂浮、人物僵站、没有前因的雨滴逆流。可换雪、墨、火等介质，保持受力逻辑。

## 八态范例

| 帧 | 可见状态 | 不应提前出现 |
|---|---|---|
| 01 蓄势 | 本体手低、自然下雨、衣摆贴身、无法相 | 巨脸、悬石、刀光 |
| 02 领域初开 | 手势启动、浅水圈抬起、近地石屑浮动 | 完整法相和巨大水墙 |
| 03 初现 | 伸手；背后同脸同手势的透明上半身 | 实体巨人、斩击 |
| 04 展开 | 控制姿势保持、巨相越屋顶、领域扩张 | 出刀收势 |
| 05 凝实 | 站位不变，脸手显肤色、发色和衣料变深，下缘散雾 | 换脸或变石雕 |
| 06 聚刃举手 | 指定手聚刃举起、重心后移；法相处于同阶段 | 已释放冲击波 |
| 07 同步释放 | 双方同侧手同向斩下、重心前移，单一刃路推动水幕 | 巨相仍举刀、本体已收刀 |
| 08 余波 | 收势、水石回落、刀尖散滴、法相边缘消散 | 第二次攻击、新领域爆开 |

武器在策划时定义是实体刀、水刃还是光刃；不能计划能量刀却在验收时临时要求金属刀。八态不是强制八张，缺少必要转折时拆帧，不需要的阶段可删。

## 组合式提示词

填写真实变量后再提交。

**恒定块**

> 生成一张独立〔画幅〕连续关键帧。参考1为批准母版，参考2为上一张通过的帧。固定〔脸/年龄/头发/衣服/识别物〕、〔机位/建筑地标/光源/色彩与材质〕。本体在〔前景位置〕，自己的同脸同装束巨相在〔后方位置〕，同一镜头两种尺度。双方对应相同解剖学手臂与动作阶段，不左右镜像翻转。〔哪只手〕持〔物品〕，另一只手〔任务〕。

**状态变化块**

> 第〔编号〕帧：〔具体姿势、手臂终点、法相透明度和材质〕。相对前帧推进〔变化〕。环境因〔动作〕发生〔可见反应〕。尚未发生〔后续动作〕，不要把母版高潮提前画入本帧。保留〔必要轮廓〕，避免〔最可能的2—3种错误〕。

**局部修正范例**

> 只改巨相的出招手。保留本体已经正确的收势、双方脸和服装、场景、机位与光线。巨相解剖学右肩在画面左侧，右臂从该肩向下跨过身体，右拳落到画面右下，刀尖指向右下，与本体收势对应。删除原先高举的右拳和旧刀轮廓，不加第三只手。左手和识别物保持原位。

左右描述仅适用这个正面构图。反打/侧面应先看图确定坐标，不能照搬。

每帧保存文件名、母版/前帧、提示词、状态、观察和通过结果。修正后更新后续参考链。概览拼图用来比较，不替代独立原图。
