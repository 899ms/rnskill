# novel-distill

从小说章节中选出一个能独立看懂、适合短视频的事件，解释为什么选它，再形成有依据的制作简报。

输入是小说材料与目标；输出是阅读范围、候选比较、因果与删留、F/P/A对照、分镜草案和连续性要求。它不包含视频生成服务，不承诺播放量或涨粉。

## 使用

将整个`novel-distill`目录放进你使用的Agent的技能目录。在Codex中可以放到`~/.codex/skills/novel-distill/`，然后明确要求使用`novel-distill`。普通对话工具也可以粘贴`SKILL.md`正文作为任务要求。

```text
使用 novel-distill，分析以下章节。
目标：约30秒小说高光预告，面向没读过原著的人。
改编尺度：保留事件因果，视听设计单列，新增情节不混进原文。
材料：【小说正文或可读取的文件】
参考：【参考图/视频与喜欢的地方】
制作工具：【例如Pexo】
先比较候选和解释取舍，再形成分镜与制作简报。
```

## 内容

- `SKILL.md`：选段、核对与转译流程。
- `references/example.md`：原创教学例子，可完整复跑；不是任何已出版小说的原文。
- `references/jianlai-case.md`：真实项目的选段与制作审查记录，不附原著全文。
- `references/failure-case.md`：一次文本试跑暴露的时序错误，以及材料不足时应该怎样输出。

## 验证范围

格式校验与实际创作判断是两回事。此版本有原创文本试跑和《剑来》制作案例。第三轮文本检验中，缺原文时拒绝编造、道具交付顺序两项通过；动作执行者和新增物理反应仍有错误，整体仅部分通过。修订后仍需核对原文与成片，没有跨模型性能评测或与其他Skill的受控对比。
